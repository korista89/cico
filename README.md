# 경은 SW-PBS 운영실

「2026학년도 학교차원 긍정적행동지원(SW-PBS) 1차년도 다층 운영 계획(안)」을 **입력 · 모니터링 · 의사결정 · 지원 · 코칭 · 피드백 · 관리**까지 한 화면에서 운영하는 웹앱입니다.
계획서와 이 웹앱 주소만 공유하면 운영할 수 있도록 설계했습니다.

- **Tier 1** (보편 100%): 3대 기대행동 × 6대 공간 매트릭스, 배움주간 직접교수, 4:1 칭찬, 토큰마켓
- **Tier 2 CICO** (5%, 9~10명): 체크인 → 교시별 DPR(0·1·2) → 체크아웃 → 금요일 주간 분석
- **Tier 3** (초고위기 2명): FBA·BIP, 일일 빈도·심리안정실·FCT 기록, 상담 기록
- **Big 5 · 월례회의(DBDM)**: 회의록과 해결계획서에 데이터가 자동으로 채워짐 · 한글(HWP) 붙여넣기용 텍스트 복사
- **자동 의사결정 기준**: CICO 80%·70%·4주 연속, Tier 3 주 3회, 다발 장소 30% 등 계획서 수치 그대로

## 구성

| 경로 | 용도 |
|---|---|
| `gas/Code.gs` · `gas/Index.html` | **실제 운영판**: 구글 Apps Script 웹앱 + 구글 시트 저장 |
| `docs/index.html` | 체험판(예시 자료 · 브라우저 저장). GitHub Pages로 열 수 있음 |
| `src/` | 원본 소스 (`plan.js` = 계획서 내용, `core.js` = 저장소·차트·판정, `v_*.js` = 화면) |
| `tools/build.py` | `src/` → `gas/Index.html` · `docs/index.html` · `dist/app.html` 생성 |

## 학교 전용 주소 만들기 (관리자 1회 · 약 5분)

1. 학교 구글 계정으로 **구글 시트**를 새로 만듭니다. (예: `2026 SW-PBS 운영 데이터`)
2. **확장 프로그램 → Apps Script**를 엽니다.
3. `Code.gs` 내용을 지우고 이 저장소의 `gas/Code.gs`를 붙여넣습니다.
4. **＋ → HTML** 파일을 `Index`라는 이름으로 만들고 `gas/Index.html` 전체를 붙여넣습니다.
5. 함수 선택에서 `setup`을 고른 뒤 **실행** → 권한 허용. 시트 탭 21개가 자동으로 생깁니다.
6. **배포 → 새 배포 → 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **학교 도메인 사용자** (또는 Google 계정이 있는 모든 사용자)
7. 나온 **웹 앱 URL**을 계획서와 함께 교직원 메신저로 공유합니다.

**선택 · 접속 코드**: Apps Script → 프로젝트 설정 → 스크립트 속성에 `ACCESS_CODE`를 추가하면 처음 접속할 때 코드를 묻습니다.
**업데이트**: `Index.html`을 새 버전으로 바꾼 뒤 배포 관리 → 수정 → 새 버전. 주소와 자료는 그대로 유지됩니다.

## 첫 설정

1. 설정 → 학교 정보 (전교생·교직원 수, 방학, 핫라인, 관리자 PIN)
2. 설정 → 교직원 명단 · 학생 명단: 엑셀에서 복사해 **붙여넣기**로 한 번에 등록
3. CICO → 선별·등록 / Tier 3 → 대상 지정
4. 성과 → 3월 TFI 기초선 입력

## 개인정보

- 자료는 학교 구글 시트에만 저장됩니다. 외부 서버를 쓰지 않습니다.
- 학생은 이름만(성 제외) 또는 학교가 정한 학생 코드로 등록하세요.
- 시트의 `json` 열은 앱이 읽는 원본이므로 수정하지 마세요. 오른쪽 열은 사람이 읽기 좋게 정리된 사본입니다.

## 개발

```bash
python3 tools/build.py   # src/ 수정 후 결과물 재생성
```

TFI 문항명은 Center on PBIS TFI 구조(Tier 1 15문항 · Tier 2 13문항 · Tier 3 17문항)의 요약 번역입니다. 공식 채점 기준은 TFI 원본 양식으로 확인하세요.
